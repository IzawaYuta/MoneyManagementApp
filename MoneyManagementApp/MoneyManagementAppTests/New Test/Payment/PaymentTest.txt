追加条件(isValid)

名前が入力されていれば追加できる
名前が空だと追加できない

追加(add)

追加した支払方法に、名前・種類・メモが保存される
メモが空文字なら nil で保存される
最初の支払方法の sortIndex は 0
追加するたびに sortIndex が末尾に増えていく(0, 1, 2)
sortIndex が飛んでいても、最大値+1 で追加される
追加した支払方法の ID は一意

削除(delete)

1件削除すると、残りの sortIndex が詰まり、順序が保たれる
複数件をまとめて削除できる
sortIndex が飛んでいても、削除後は 0 から詰め直される
全件削除して 0 件になっても削除できる
削除対象が空なら何も変わらない
存在しない ID を指定しても、他の支払方法に影響しない
削除後に追加すると、詰め直した sortIndex の末尾に入る
支払方法を削除しても、過去の収支記録(Transaction)の支払方法情報は残る

最近の支払い(recent)

収支記録がなければ、空になる
最近使った順に返される
同じ支払方法を何度使っても、1件にまとまる
4件以上使っていても、最大3件までしか返さない
支払方法が未設定(nil)の収支記録は無視される
削除済みの支払方法は含まれず、3件の枠も消費しない
